## 2. 设计原则（评审时按此打分）

1. **内容是主角**：chrome（导航/边框/装饰）总视觉权重 ≤ 20%；资产 tile 永远最亮。金色只给「当前选中/主 CTA」，不大面积铺。
2. **快是可见的**：骨架屏、加载反馈、结果耗时（「~12ms」）都要被设计成正向体验，而不是遮丑。
3. **信任感**：license 徽标、「⌂ 本站直链」徽标是品牌资产的一部分，位置固定、样式统一，让用户形成条件反射。
4. **双主题平权**：每个页面先出暗色再出亮色（暗色是开发者主力场景），两套都过 AA 对比度才算完成。
5. **等宽网格纪律**：mascot 墙维持全等方格（产品已定，不做宽窄混排 bento）。

## 3. 设计令牌（Design Tokens）交付要求

在 Figma 用 Variables 建立三层令牌（primitive → semantic → component），与代码 CSS 变量一一对应命名：

```
primitive:  gold.500=#c9a227  gold.600=#8b6914  ink.900=#1a1a1a  gray.500=#6b6b6b ...
semantic:   --accent(金) --link --ink --mut --line --card --bg --glow --chipbg --nav-bg
component:  --tile-bg --tile-radius --chip-bg-active --btn-primary-bg ...
```

- 间距用 4pt 基数（4/8/12/16/24/32/48），圆角统一 3 档：tile 8px / 卡片 12px / 弹窗 16px；
- 字阶 5 档：12/14/16/20/28（hero 标题可到 36），行高 1.5；
- 网格：桌面 tile 最小 96px、间距 12px；768px 下 80px；390px 下 4 列 72px。

## 5. 组件规格清单（Figma 组件库，含变体与状态）

每个组件交付：默认/悬停/按下/选中/禁用/加载 6 态 × 亮暗 2 主题，并标注焦点圈（focus-visible 2px gold）。

1. **AssetTile**（图标/吉祥物/插画三变体）：等宽正方，hover 浮起 2px + 边线变金；选中态左上金底对勾；懒加载占位用品牌 glow 色 8% 透明度；
2. **交付区 DeliverPanel**：主按钮（金底 ink 字，禁用灰）、尺寸矩阵（segmented）、复制下拉（菜单内行内代码样式）；
3. **Chips**（分类/库）：默认/选中（金边金字底 glow）/折叠「…更多」态；
4. **TrustBadge**：license 徽标（MIT/Apache/CC0/CC BY 配色区分，蓝绿系不与金冲突）+ ⌂ 本站直链徽标 + 外站 ↗ 徽标；
5. **BottomTray**（批量托盘）+ **BottomSheet**（移动详情）；
6. **Toast**（过程类）/ 就地确认（按钮内绿勾，沿用现行方案）；
7. **SkeletonTile / EmptyState / ErrorState**：空态插画**必须用本站 mascot 出镜**（品牌记忆点，禁止外采插画）；
8. **顶栏 / 底部 tab bar（移动）/ 页脚**：沿用 kg 基座，顶栏加三品类 tab。

## 8. 红线（一票否决）

1. 任何页面出现远程字体/图片依赖；
2. 亮暗任一主题文本对比度 <4.5:1（正文）/<3:1（大字与图形）；
3. 金色面积 > 视口 15%（内容主角原则失守）；
4. tile 宽窄混排（破坏等宽网格纪律）；
5. 隐藏或弱化 license 徽标。
