## 三、发现并修复的缺陷（共 4+2 环境类）

| 缺陷 | 根因 | 修复 |
|---|---|---|
| 切插画 tab 无反应 | 忘加 `tabIllus.onclick` 绑定 | 补绑定 |
| 切头像风格后不渲染 | asRender 未预载新风格模块 | asRender 内 `await asMod(AS.style)` |
| 背景色不生效 | `bg.slice(1)` 误削无#色值首字符 | `bg.replace(/^#/,'')` |
| 深链种子不回填 | asInit 二次调用被 ready 挡 | 深链分支显式回填 + 重渲染 |
| 插画 404 | manifest 包 id（3d）与目录（3dicons）不一致 | 目录统一为 `illus/3d/` |
| 【环境】本地浏览器吃旧模块 | copy2 保留源包旧 mtime → 启发式缓存数月不回源 | 脚本 copy 后 `os.utime` 刷新；测试换端口 |
| 【环境】线上首验失败 | GitHub Pages max-age=600 内浏览器命中旧 HTML | cache-buster 复验通过（非产品缺陷） |
