# IconGems 产品规划 V2 —— 「全自托管 · 三品类一站式」

> 角色：产品经理 ｜ 日期：2026-10-24 ｜ 状态：待评审
> 上游输入：现有站点 icongems.kuige.me（单文件 index.html，GitHub Pages）
> 本版核心变更：**所有资产全部自托管在本站，用户不再去外站下载任何东西**（owner 明确要求，2026-10-24）

---

## 1. 定位与愿景

**一句话定位**：免费、免登录、全自托管的图标 + 头像/IP + 插画资源站——搜索、预览、下载全部在本站完成。

**愿景**：成为全球最大的免费「图标 · 头像 · 插画」一站式资源站。

**三个产品主张**（对用户的承诺）：

| 主张 | 含义 | 对应能力 |
|---|---|---|
| **全在本站** | 每一个文件的预览和下载都来自本站域名，不跳转、不外链下载 | 全量资产自托管，零运行时外站依赖 |
| **永久免费** | MIT / Apache / ISC / CC0 资产为主，商用免署名，license 逐项标注 | license 徽标体系（已有，需强化） |
| **机器可读** | 人和 AI agent 都能一条链路取完资产 | llms.txt / catalog.json 管道（已领先，保留并改为本地端点） |

## 2. 现状盘点（AS-IS）

### 2.1 资产结构

| 品类 | 现状 | 数量 | 自托管程度 |
|---|---|---|---|
| 头像 / IP 吉祥物 | IP as Logo 库，默认 tab | 3,448 个（MIT） | 预览 512px WebP 已自托管（31MB）；**原图 1254px PNG 运行时从 cdn.ipaslogo.com 拉取** ❌ |
| 图标 | 聚合 29 个开源库 | 109,813 枚 SVG | **全部运行时依赖 api.iconify.design**（搜索/SVG/PNG）❌ |
| 插画 | 页尾 16 个外链站 | 0 个本站资产 | 纯外链 ❌ |

### 2.2 核心问题诊断

1. **运行时强依赖外站 = 最大产品风险**。图标 tab 的搜索、渲染、下载 100% 依赖 api.iconify.design；吉祥物原图依赖 cdn.ipaslogo.com。外站限流、故障、被墙（README 已记录 CN 网络下 Supabase 不可达的先例）都会直接击穿本站核心功能。这与「下载就在本站发生」的产品承诺矛盾。
2. **品类失衡**。口号是「图标+头像+插画」，实际只有前两者可用，插画是外链目录，用户被送离本站。
3. **单页应用吃不到长尾 SEO**。109,813 枚图标、3,448 个吉祥物每一个都是长尾搜索词（如 "rocket svg download"），目前只有一个 index.html。
4. **无用户资产**。没有收藏、没有下载历史，用户无回访钩子。

### 2.3 已有优势（保持并放大）

- 吉祥物库全网稀缺：3,448 个 MIT 授权 IP 形象，「头像」品类天然领先；
- 零依赖单文件架构：启动快、维护成本极低；
- AI-first 管道（llms.txt / catalog.json / robots 欢迎 AI 爬虫）在同类站中领先；
- 中英双语 + 三主题（auto/light/dark）+ 客户端 ZIP 批量打包。

## 3. 目标用户与核心场景

| 用户 | 场景 | 今天的不爽 | 自托管后的体验 |
|---|---|---|---|
| **开发者** | 找图标 → 复制 React/Vue 代码或下载 SVG | 图标要等 api.iconify.design 响应，慢且偶发失败 | 毫秒级本地命中，代码复制即走 |
| **设计师** | 找 mascot/IP 原图、批量取一组图标 | 原图从外站 CDN 拉，速度与稳定性不受本站控制 | 本站直链，下载进度可见 |
| **自媒体 / 普通用户** | 换头像、找装饰图 | 预览在本站、大图在外站，体验割裂 | 所见即所得，点击即得 |
| **AI agent** | 按 llms.txt 链路批量取资产 | SVG 端点指向第三方 | 全链路本站域名，可镜像可离线 |

## 4. 北极星与指标树

**北极星指标**：周成功交付资产数（下载 + 复制代码，单事件去重）

```
周成功交付资产数
├── 到访 → 搜索/浏览转化率（目标 ≥ 55%）
│   ├── 首屏三品类直达点击率
│   └── 搜索空结果率（目标 ≤ 10%）
├── 浏览 → 交付转化率（目标 ≥ 25%）
│   ├── 资产详情打开率
│   └── 下载/复制成功率（目标 ≥ 99%，自托管后消灭外站超时）
└── 回访率（P1 收藏功能后目标周回访 ≥ 12%）
```

**质量红线**（自托管专项）：核心链路 DevTools Network 中，**运行时外部请求 = 0**（统计/字体除外，需单独评审白名单）。

## 5. 路线图

### P0（0–4 周）：「归巢计划」—— 全量自托管迁移 🔴 本版最高优先级

> 目标：用户在本站完成 100% 的预览与下载；拔掉两根外站依赖管子。

**P0-1 图标库本地化（29 sets / 109,813 枚）**

- 离线拉取 29 个集合的 Iconify 格式 JSON（`/icons/{prefix}.json`，含全部 SVG path 数据），逐 set 提交进仓库；
- 建立轻量名称索引 `/data/icon-index.json`（prefix + name + 别名，约 3–5MB），首屏只加载索引，set 数据按需 fetch；
- 前端搜索引擎本地化：子串匹配 + 常见别名（沿用现有 expandTerm 思路），SVG 由本地 JSON 客户端渲染（现有 buildSvg 改数据源），PNG 继续用 canvas 导出；
- `liveCounts`（实时计数）改为读本地 manifest 常量。

**P0-2 吉祥物原图自托管（3,448 个）**

- 全量转码：原图 1254px PNG → **1024px WebP（带 alpha）**自托管于 `/ipas/full/`（估算 60–120MB，实施前先抽 100 个实测平均体积）；
- 详情弹窗「下载 PNG」改为下载本站 1024px WebP + 提供本站转存版 PNG（无损需求用户占少数，先 WebP 全量，PNG 二期按需）；
- ZIP 批量包内的原图同样替换为本站文件。

**P0-3 插画品类过渡**

- 16 个外链保留但每个卡片加「外站」徽标（诚实标注，P1 替换）；
- 启动可自托管插画库的 license 审查：**Open Peeps（CC0）、Humaaans（CC0）、Lukasz Adam（CC0）、illlustrations.co（开源）、3dicons（CC0）、IRA Design（MIT）** 为候选首批；unDraw（禁止再分发）、Storyset/DrawKit/Ouch（署名+限制）**不入池**。

**P0-4 管道与文案同步**

- llms.txt / llms-full.txt / catalog.json 的 SVG 端点全部改写为本站路径；robots.txt 不变；
- 页面所有「live via api.iconify.design」「源：ipaslogo CDN」类文案改为「本站直链」；
- API 示例代码块（apiCode）改成本站等效端点。

**容量预算**（GitHub Pages：站点软限 1GB / 单文件 <100MB）：

| 项 | 估算 | 累计 |
|---|---|---|
| 现有站点（含 31MB 预览） | ~35MB | 35MB |
| 29 sets 图标 JSON | 40–80MB | ≤115MB |
| 名称索引 | 3–5MB | ~120MB |
| 吉祥物 1024px WebP 全量 | 60–120MB | **≤240MB** ✅ |

超限预案：icon JSON 按季度快照分仓（data 仓 submodule）或整体迁 Cloudflare Pages（静态免费无带宽焦虑）。

**验收口径**：断网外站（屏蔽 api.iconify.design 与 cdn.ipaslogo.com 域名）后，三品类搜索、预览、单个下载、ZIP 批量全流程可用。

### P1（1–3 个月）：品类成型 + 留存钩子

- **头像品类独立**：mascot 库升级为「头像/IP」一级品类；接入 DiceBear 本地渲染（开源自托管，风格级 license 审查）做「头像生成器」——选风格→改种子/配色→导出，形成 UGC 式传播点；
- **插画自托管首批上线**：P0-3 审查通过的 CC0/MIT 库，逐包入库（预览 WebP + 原文件 ZIP），页面形态从外链列表升级为与图标一致的网格浏览+下载；
- **批量勾选模式 + 已选托盘**（详见交互文档 02）；
- **收藏夹与下载历史**（localStorage，免登录，导出 JSON）；
- **SEO 基建一期**：每个图标 set / 每个 mascot 分类生成静态落地页（构建时输出，GitHub Pages 直接托管），sitemap 扩容。

### P2（3–6 个月）：规模与生态

- 图标库从 29 sets 扩到 100+（继续逐 license 审查入池），冲击「最大聚合」心智；
- 每枚图标/每个 mascot 独立可索引页（预渲染，长尾 SEO 二期）；
- 对外提供本站 API（静态 JSON 端点即可），成为 AI agent 取图标的默认入口之一；
- 插画库扩容 + 按风格/配色筛选；多语言（日/韩/西）。

## 6. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 再分发许可风险 | 高 | 入库前逐库核对**再分发**条款（不只是"免费使用"）；每个资产保留 LICENSE 原文与来源链接；CC BY 4.0 集合在页面与 ZIP 内附署名文件 |
| 仓库体积超限 | 中 | 季度快照分仓 / 迁 Cloudflare Pages；图片先实测再全量转码 |
| 前端索引搜索质量下降（无后端） | 中 | 名称索引带别名与常见错拼；热门词预置同义词表；空结果时给分类推荐而非死胡同 |
| 单文件 index.html 膨胀 | 中 | P0 拆出可缓存的 data 层（JSON 已外置）；逻辑仍可单文件，超过阈值再评估轻量构建 |
| 外站迁移期数据漂移（上游更新） | 低 | 季度重跑 fetch 脚本刷新快照，catalog 记录数据日期 |
