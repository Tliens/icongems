# IconGems 验收标准 —— 视觉验收 + 用户角度验收

> 角色：产品经理（终审）+ 交互设计师（走查）+ 视觉负责人（自查）
> 适用版本：P0「归巢计划」（全自托管）+ 三品类改版
> 原则：**每条验收项必须可执行、可判 pass/fail**；不接受「看起来还行」。

---

## 一、验收流程与时点

```
设计稿完成后   → 【视觉验收】D1-D4 每阶段：视觉自查 → 交互走查 → PM 终审
开发完成后     → 【用户角度验收】5 个任务剧本 + 环境矩阵，PM 主持，邀请 ≥3 名真实用户（或角色扮演者）
上线前 24h     → 【红线扫描】一票否决项全量过一遍
上线后 1 周    → 数据复盘：北极星与质量红线指标对照
```

## 二、视觉验收清单（针对设计稿与实现，共 40 项）

### A. 品牌一致性（6 项）

| # | 验收项 | Pass 标准 |
|---|---|---|
| A1 | 主色使用 | 仅 `#c9a227`（暗色提亮档）作为强调色；无同义新色 |
| A2 | 金色面积 | 任一屏金色占比 ≤15% |
| A3 | logo/favicon | 顶栏、页脚、OG、favicon 四处 mascot 一致（v3 圆角规范） |
| A4 | 中性色 | 全部走 kg 基座令牌，无游离灰值 |
| A5 | 圆角/间距 | 只用令牌档位（8/12/16px；4pt 间距），无随手值 |
| A6 | 字阶 | 只用 5 档字阶，中英文均不溢出 |

### B. 布局与响应式（8 项）

| # | 验收项 | Pass 标准 |
|---|---|---|
| B1 | 390px | 无横向滚动；三品类底部 tab bar 可用；详情为 bottom sheet |
| B2 | 768px | 网格 80px tile，chips 折叠 ≤1 行 |
| B3 | 1280px | 内容最大宽度与现有 wrap 一致，两侧留白均匀 |
| B4 | tile 等宽 | mascot 墙全等方格，无混排 |
| B5 | 长网格 | Fluent 全集（19,876）滚动无卡顿、无布局跳动 |
| B6 | 底部托盘 | 出现/收起不遮挡内容关键区，滚动常驻 |
| B7 | 焦点圈 | 全组件 focus-visible 可见（2px gold） |
| B8 | 弹窗 | 焦点陷阱 + Esc 关闭 + 焦点还原 |

### C. 双主题与可访问性（6 项）

| # | 验收项 | Pass 标准 |
|---|---|---|
| C1 | 暗色完整度 | 全部页面/状态有暗色版，无「暗色下看不清」区域 |
| C2 | 对比度 | 正文 ≥4.5:1，大字/图形 ≥3:1（工具实测，截图存档） |

| C4 | 动效 | prefers-reduced-motion 下全部动效停止 |

| C6 | 图片替代 | 资产 tile 有 aria-label（名称+品类） |

### D. 状态与反馈（6 项）

| # | 验收项 | Pass 标准 |
|---|---|---|
| D1 | 骨架屏 | 弱网下网格/弹窗有 shimmer 占位，无白屏 |
| D2 | 空态 ×3 品类 | mascot 出镜 + ≥2 条出路（推荐词/分类） |
| D3 | 错误态 ×2 | 索引失败与资产缺失文案区分，均有动作按钮 |

| D6 | 加载耗时展示 | 本地搜索结果展示耗时文案（「~x ms」） |

### E. 资产质量与信任（6 项）

|---|---|---|

### F. 交付区一致性（4 项）

| # | 验收项 | Pass 标准 |
|---|---|---|
| F1 | 结构统一 | 三品类弹窗交付区布局一致 |

### G. 一票否决红线（4 项）

| # | 红线 | 判定方法 |
|---|---|---|
| G1 | **零外部运行时请求** | DevTools Network（屏蔽统计白名单后）无 api.iconify.design / cdn.ipaslogo.com / 任何第三方字体图片 |

| G3 | 对比度任一 < 标准 | C2 抽查任一页失败即整版打回 |
| G4 | 远程资源依赖 | 设计稿或实现引入远程字体/图片 |

## 三、用户角度验收（任务剧本 UAT）

> 每剧本由对应 persona 的真实用户（或严格角色扮演）执行，PM 旁观察不提示，记录：完成步骤数 / 耗时 / 卡点 / 失败即判 fail。

### 剧本 1 · 开发者小林：「给我的 React 项目找个火箭图标」
- **输入**：`/` 键 → 输入 rocket → 选择 lucide 库 → 复制 React 代码 → 粘贴到自己项目。
- **Pass**：≤6 步、≤60s；复制的代码直接编译通过；全程键盘可完成。
- **关注点**：搜索联想是否被使用；库筛选是否可发现。

### 剧本 2 · 设计师阿紫：「下载一个狐狸 IP 形象做品牌吉祥物」
- **输入**：进入头像·IP 品类 → 分类找到狐狸 → 打开详情 → 下载最高清版本 → 检查透明背景。
- **Pass**：≤5 步；下载的文件在本地直接可用（1024px+、透明通道完好）；弹窗内可见 MIT license 与商用说明。
- **关注点**：是否会找「PNG」而困惑只有 WebP（观察文案是否解释）。

### 剧本 3 · 自媒体用户王姐：「换个新头像，不要可爱的，要酷的」
- **输入**：首页 → 头像·IP → 浏览/搜索 → 下载一个。
- **Pass**：无需任何专业知识；不出现英文障碍（中文界面完整）；下载成功有明确反馈；≤4 步。
- **关注点**：非技术用户是否理解 WebP（手机相册/微信能否直接用——不能则 P0 决策点 2 需重评 PNG）。

### 剧本 4 · 批量用户老赵：「把这 6 个动物头像打包下载」
- **输入**：头像品类 → 进入选择模式 → 勾选 6 个 → 托盘 → 下载 ZIP → 解压。
- **Pass**：ZIP 内恰好 6 个文件且命名可读（动物名）；≤8 步；ZIP 生成有进度反馈。
- **关注点**：勾选模式入口是否可发现；误选后如何取消。

### 剧本 5 · 大陆无代理用户小陈（自托管专项）：「公司网络屏蔽了外网 CDN」
- **输入**：hosts 屏蔽 api.iconify.design 与 cdn.ipaslogo.com → 全流程重做剧本 1、2、4。
- **Pass**：全部通过且首屏 LCP <2.5s；页面任何位置不出现加载失败。
- **关注点**：这是自托管迁移的**终局验收**，fail 则 P0 不算完成。

### 环境矩阵（每个剧本至少覆盖）

| 维度 | 取值 |
|---|---|
| 浏览器 | Chrome / Safari / Firefox 最新版 |
| 设备 | 桌面 1280 + iPhone SE 390 |
| 主题 | 亮 / 暗 |
| 语言 | 中 / 英 |
| 网络 | 正常 / Fast 3G / 屏蔽外站域名 |
