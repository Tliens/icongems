⚖️ Licenses & AI

MIT / Apache-2.0 / ISC / CC0 icon sets are safe to reference in AI prompts and generated code. CC BY 4.0 sets need attribution. Careful with illustrations: some libraries (e.g. unDraw) prohibit AI/ML training use — check before bulk ingestion.

FAQ

Are these icons free for commercial use?

Yes — every library featured here is open source. MIT, Apache-2.0, ISC and CC0 sets can be used in commercial products without attribution. CC BY 4.0 sets (Solar, Font Awesome Free, Twemoji) are also free for commercial work but ask you to credit the authors. Each card shows the exact license; always confirm on the source site before shipping.

How do downloads work? What formats do I get?

Click any icon to open its detail panel: copy SVG, React, Vue, HTML or CSS snippets, download the SVG file, or render and download a PNG (64–512 px) right in your browser. No signup, no watermark.

Where do the icons come from?

IconGems searches via the Iconify API, which aggregates 200+ open-source icon sets — Google Material Symbols, Microsoft Fluent UI, Tabler, Lucide, Phosphor, Font Awesome, Bootstrap and more. Icons are always served fresh from upstream; IconGems is a search front-end, not a host.

Do I have to give credit anywhere?

For MIT / Apache-2.0 / ISC / CC0 libraries: no attribution required (keeping the license notice in your project is good practice). For CC BY 4.0 libraries (Solar, Font Awesome Free icons, Twemoji): attribution is required. Illustration libraries vary — each card in the illustrations section links to the exact license.

Can I use these icons with AI code generation?

Yes. Permissively licensed icon sets (MIT/Apache/ISC/CC0) are fine to reference in AI prompts, code generation and shipped products. This site also publishes llms.txt and a machine-readable catalog at /data/catalog.json for AI agents. Note: some illustration libraries (e.g. unDraw) explicitly prohibit using their artwork for AI/ML training — check each source's terms before bulk ingestion.

Is IconGems affiliated with Google, Microsoft or the other brands?

No. IconGems is an independent search front-end over open-source icon collections. All library names and trademarks belong to their respective owners, and every card links back to the official source.

What are the mascot logos? Can I use them commercially?

The mascot collection comes from IP as Logo (ipaslogo.com), generated with the MIT-licensed IP as Logo Skill — 3,448 rounded, subtly neo-skeuomorphic character logos across animals, nature, food, objects and symbols. MIT means free commercial use, no attribution required. Original PNGs stream straight from the project CDN when you click download; 512px WebP previews are hosted by IconGems, so browsing stays fast and works even if the source is slow.

Why do mascot categories sometimes look approximate?

The source site keeps its own category table behind an API that is unreachable from some networks, so IconGems derives categories from each mascot's descriptive slug (e.g. “chubby-panda” → animals) with a curated keyword dictionary — accurate for the vast majority. When in doubt, search by keyword instead of browsing by category.
